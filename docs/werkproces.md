## Code Reviews

Voordat een branch ge-merged kan worden naar de dev branch, moet de branch eerst een merge request krijgen die gereviewd moet worden. Dat reviewproces kan alleen gedaan worden door developers met technische ervaring: Amin, Benito en Tess.

Hierbij wordt dan gekeken naar de duidelijkheid van de code, kunnen delen beter of duidelijker opgeschreven worden, en de kwaliteit van de code, zijn er enige bugs die niet eerder gezien werden. Het belangrijkste om te onthouden is dat het doel van de code reviews niet is om de code "perfect" te maken. Tijdens de review wordt er niet gelet op de kleinste details, het gaat er meer om het grootte geheel.

### Belangrijkste punten tijdens een review

- De structuur van de code, is het makkelijk te volgen en duidelijk.
- De gebruikte oplossingen binnen de code, zijn de problemen die voortkwamen op de beste manier opgelost.
- De mogelijke valkuilen binnen de code, waar kunnen bugs ontstaan of zijn er momenteel bugs.
